# CHIMERA -- Computational Hyperbolic Input–output MIMO Equation Routines & Algebra  

This toolbox contains routines for computations on MIMO hyperbolic PDE-ODE-Systems.

**Warning:** This toolbox contains research code and is in an early stage, the API may change any time.

## Structure and Usage

The most important functions can be found in the main namespace. Just run

```
>>> import chimera as ch
```

an you are good to go.
